Cuatro

    
Cómo se lleva esto al sitio

    
El sitio está hecho de piezas con nombre. Para cambiar una sola cosa no se toca el diseño entero: se le pone un nombre nuevo y se le da una regla.

    
Paso 1 · En el HTML, dale un nombre a lo que quieres cambiar:

  <h2 class="encabezado__titulo titulo--resaltado">¿Qué te está costando dinero?</h2>
                                    └── esto es nuevo

Paso 2 · En css/components.css, escribe la regla al final:

  .titulo--resaltado {
    box-shadow: inset 0 -0.55em 0 rgba(214, 36, 122, 0.30);
  }

Paso 3 · Recarga la página. Si no cambia nada, revisa que el nombre
         esté igual en los dos sitios (el HTML y el CSS).
