# La investigación del taller se mudó fuera del repositorio

Este archivo estaba aquí y ya no: **el repositorio es público**, así que `docs/` se
puede leer entrando a GitHub aunque no se publique en el sitio, y este documento
cita las palabras de una persona identificable del taller. Una transcripción no es
una métrica: es alguien hablando de su trabajo.

Ahora vive en la carpeta privada de los productos, junto a los demás documentos que
nombran a personas:

```
~/productos-camena/privado/investigacion-taller.md            (el análisis: 9 problemas, con citas)
~/productos-camena/privado/transcripciones/primera-ronda.md   (las 13 notas de voz, transcritas)
~/productos-camena/privado/contactos.md                       (teléfonos y correos)
```

Lo que sí se queda aquí, porque no lleva datos de nadie: la valoración del sistema
(`docs/valoracion-control-de-autos.md`), las preguntas de la segunda ronda
(`docs/preguntas-taller-segunda-ronda.md`) y todo lo técnico.

**Nota honesta:** sacar los archivos no los borra de la historia de git: quien mire
los commits anteriores a esta mudanza todavía puede leerlos. Si eso importa, hay que
reescribir la historia publicada —que se puede, pero se hace a conciencia—.
